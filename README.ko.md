# 워치 미니게임

> 갤럭시 워치·모바일·PC 브라우저에서 가볍게 즐기는 터치 미니게임 모음입니다.

[온라인 플레이](https://minantonio46.github.io/watch-minigames/) · [English](README.md) · [GitHub 저장소](https://github.com/minantonio46/watch-minigames)

HTML, CSS, 순수 JavaScript로 만든 빌드 없는 정적 웹 프로젝트입니다. 원형 워치 화면을 중심으로 설계했지만 모바일과 데스크톱에서도 플레이할 수 있습니다.

## 포함된 게임

- **반응속도** — 화면이 초록색으로 바뀌는 순간 탭합니다.
- **10초 연타** — 10초 동안 최대한 많이 탭합니다.
- **5초 맞추기** — 보이지 않는 타이머를 5.000초에 최대한 가깝게 멈춥니다.
- **러너** — 짧은 탭과 홀드 점프로 장애물을 피합니다.
- **블랙잭** — 뱅크롤과 캐시아웃 최고 기록을 지원하는 미니 블랙잭입니다.
- **스택 타워** — 움직이는 블록을 정확히 쌓아 올립니다.
- **오빗 캐치** — 회전 포인터가 목표 호 안에 들어올 때 탭합니다.

## 주요 기능

- 한국어·영어 전환
- 다크·라이트·기기 설정·OLED 친화 고대비 테마
- 터치·마우스·키보드 조작
- 로컬 최고 기록 및 즐겨찾기 저장
- 게임별 인앱 가이드
- 프레임워크·패키지 설치·빌드 단계 없음

## 로컬 실행

저장소를 내려받은 뒤 최신 브라우저에서 `index.html`을 열면 됩니다. 로컬 웹 서버는 선택 사항입니다.

## 배포

라이브 사이트는 `main` 브랜치의 저장소 루트에서 GitHub Pages로 제공됩니다. 배포 전 확인 항목은 [배포 안내](docs/DEPLOYMENT.md)를 참고하세요.
