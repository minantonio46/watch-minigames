# 워치 미니게임

갤럭시 워치의 웹 브라우저에서 가볍게 즐기는 터치 미니게임 프로젝트.
HTML, CSS, JavaScript만 사용하며 서버, 패키지 설치, 빌드가 필요 없습니다.

- 게임: https://minantonio46.github.io/watch-minigames/
- 저장소: https://github.com/minantonio46/watch-minigames
- 배포 설정: `main` 브랜치의 `/(root)` (GitHub Pages)
- 로컬 `origin`과 `main`의 upstream 연결 완료. TortoiseGit에서 Commit → Push로 업데이트합니다.

## 메뉴 및 설정

- **순환형 카드 캐러셀 & 모션**: 화면 가운데 현재 선택된 카드가 크게 표시되고 양옆의 대기 중인 카드에도 실제 게임의 아이콘과 제목이 채워져 미리보기 형태로 자연스럽게 표시됩니다. 끝에 도달하면 멈추지 않고 순환(무한 루프) 형식으로 계속 돌 수 있습니다. 좌우 실시간 드래그 반응, 부드러운 스냅 전환 애니메이션(`slide-in`), 터치 피드백, 즐겨찾기 팝 애니메이션 등 워치 화면에 최적화된 가볍고 자연스러운 모션이 적용되어 있습니다.
- **즐겨찾기(★)**: 하단의 별 아이콘을 누르면 해당 게임이 즐겨찾기로 등록되어 메뉴 맨 앞쪽에 우선 정렬되며 브라우저에 저장됩니다.
- **설정 카드**: 메뉴 설정 카드에서 언어(한국어 / English), 화면 테마(다크 / 라이트 / 기기 설정 / 고대비), 게임별 튜토리얼(개요, 워치 터치 및 PC 키보드 단축키, 공략 팁), 그리고 게임별 최고 기록 초기화를 관리할 수 있습니다. 설정값은 브라우저에 저장되어 재접속 시에도 유지됩니다. PC 브라우저에서는 마우스 드래그 스크롤을 지원하며, 키보드 방향키(상하 스크롤 / 옵션 탐색), PageUp/PageDown, Escape(메뉴 복귀)로도 조작할 수 있습니다.

## 실행

첫 화면 카드에서 게임을 선택합니다. 각 게임 하단의 `‹ 메뉴`를 누르면 선택 화면으로 돌아가며 진행 중인 판은 취소됩니다.
브라우저 뒤로 가기도 지원합니다.

- 반응속도: 화면이 초록색이 되면 터치합니다. 낮은 ms 기록이 최고 기록입니다.
- 10초 연타: 시작 터치 이후 10초 동안 누른 횟수를 셉니다. 많은 횟수가 최고 기록입니다.
- 5초 맞추기: 시작 후 감각으로 5초를 세고 다시 터치합니다. 5초와의 오차가 작을수록 좋습니다.
- 러너: 화면을 탭해 장애물을 넘습니다. 누르는 시간을 조금 더 유지하면 더 높고 오래 점프합니다. 오래 달릴수록 점수가 오릅니다.
- 블랙잭: 판돈을 정하고 21에 가깝게 맞춥니다. 딜러는 17 이상에서 멈추며 내추럴 블랙잭은 3:2로 지급합니다.

러너에서는 첫 터치가 게임만 시작하며 점프에는 쓰이지 않습니다. 이후 짧은 터치는 낮은 점프, 길게 누르면 높은 점프가 이어집니다. 바닥·공중 장애물의 높이와 길이를 보고 위로 넘거나 아래로 통과합니다. 장애물 종류·크기는 500점에 최대치가 되며, 이후에는 속도만 아주 천천히 계속 상승합니다. 사망 뒤에는 손을 뗀 후 새로 터치해야 재시작합니다.

게임별 최고 기록은 각각 저장됩니다. 게임 조작은 메뉴 버튼을 제외한 화면 전체에서 가능합니다.
설정의 **최고 기록 초기화**는 별도 확인 창에서 확정해야 실행되며, 기록만 삭제하고 언어·테마·즐겨찾기는 유지합니다.

로컬에서는 `index.html`을 브라우저로 열면 됩니다.
첫 게임은 화면 전체가 초록색으로 바뀌면 화면 아무 곳이나 누르는 반응속도 게임입니다.
시작과 재시작도 화면 어디서나 가능합니다. PC 브라우저에서는 키보드만으로 모든 게임을 즐길 수 있습니다:
- **메인 메뉴**: 좌우 방향키로 탐색, Enter/Space로 선택된 게임/설정 진입, F키로 즐겨찾기 토글.
- **반응속도 / 10초 연타 / 5초 맞추기 / 러너**: 스페이스·엔터는 물론 키보드의 아무 키나 눌러도 즉시 액션/점프가 작동합니다. 러너는 키를 꾹 누르고 있으면 최고 점프를 뜁니다.
- **블랙잭**: 방향키 상하/좌우로 판돈 조절, Space/Enter로 시작 및 카드 받기(Hit), S키나 아래 방향키로 스탠드(Stand), C키로 이어하기, N키로 기록 후 새로하기.
- **공통**: 언제든 Escape 키를 누르면 진행을 멈추고 메인 메뉴로 돌아갑니다.
최고 기록은 해당 브라우저에 저장됩니다. 저장이 차단되어도 게임은 실행됩니다.
화면이 꺼지거나 다른 탭으로 전환되면 러너는 안전하게 중단되어 새 터치로 다시 시작할 수 있습니다. 블랙잭은 진행 중인 패와 딜러 순서를 보존하고 돌아왔을 때 이어집니다.
실제 워치의 브라우저, 화면 배율, 절전 동작에 따른 확인은 필요합니다.

## TortoiseGit과 GitHub

이 폴더 자체가 Git 저장소 루트입니다. TortoiseGit은 같은 `.git` 저장소를 사용하는 Windows GUI입니다.

1. GitHub에서 빈 `watch-minigames` 저장소를 만듭니다. 무료 계정에서 Pages를 사용하려면 공개 저장소로 시작하면 됩니다.
2. 폴더 우클릭 → TortoiseGit → Settings → Git → Remote에서 `origin`을 추가하고 GitHub 저장소 URL을 넣습니다.
3. 변경한 파일을 Git Commit → `main`으로 커밋한 뒤 Push합니다.
4. GitHub 저장소의 Settings → Pages → Build and deployment에서 **Deploy from a branch**, **main**, **/(root)**를 선택하고 저장합니다.
5. 배포 완료 후 `https://계정명.github.io/watch-minigames/`를 워치 브라우저에서 엽니다. 정확한 주소는 Pages 화면에 표시됩니다.

이후 수정 → Commit → Push하면 Pages에 반영됩니다. 첫 배포와 업데이트에는 시간이 걸릴 수 있습니다.
저장소 이름이 다르면 URL의 마지막 경로도 바뀝니다. 외부 서비스 키나 비밀정보를 파일에 넣지 마세요.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 개발 기준

- 작은 원형 화면의 중앙에 핵심 정보와 버튼 배치
- 큰 터치 영역, 드래그나 키보드 없이 조작
- 외부 폰트·라이브러리 없이 적은 요청과 작은 파일 유지
- 상대 경로 사용으로 GitHub Pages 저장소 하위 경로 지원
- 짧은 플레이 시간, 백그라운드에서 게임 중단

## 확인 항목

- 카드 메뉴 좌우 스와이프/양옆 터치로 게임 이동 및 오작동(드래그 중 게임 진입) 방지 확인
- 즐겨찾기(★) 등록 시 최우선 순위로 앞쪽 정렬 및 재접속 후 유지 확인
- 설정에서 언어(한국어/영어), 테마(다크/라이트/기기 설정) 변경 및 전체 UI 즉시 반영 확인
- 화면 아무 곳 터치 → 대기 → 전체 화면 초록색 → 터치 → 기록 표시
- 대기 중 터치 시 실패 처리 및 재시작
- 탭을 숨겼다가 돌아오면 재시작 가능
- 새로고침 후 최고 기록 유지 (저장 가능한 브라우저)
- 실제 워치 및 데스크톱에서 글자와 버튼이 원형 화면 밖으로 잘리지 않는지 확인
